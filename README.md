# 📱 컨템포러리 브랜드 매장 성과 분석 PWA

F&F 통합영업팀 | Progressive Web App

## 📱 모바일에서 앱으로 설치하기

https://dindu0506.github.io/2025-Contemporary-Sales-Dashboard

### Android (Chrome)
1. 위 URL을 Chrome에서 열기
2. 하단에 "홈 화면에 추가" 배너 표시됨
3. `설치` 버튼 클릭
4. 홈 화면에 아이콘 생성! ✅

또는:
- 브라우저 메뉴(⋮) → "홈 화면에 추가"

### iOS (Safari)
1. 위 URL을 Safari에서 열기
2. 하단 공유 버튼(📤) 클릭
3. "홈 화면에 추가" 클릭
4. "추가" 버튼 클릭
5. 홈 화면에 아이콘 생성! ✅

---

## 💡 다른 무료 호스팅 옵션

### Netlify (드래그 앤 드롭, 초간단)
1. https://netlify.com 접속
2. 회원가입 (무료)
3. `Add new site` → `Deploy manually`
4. 3개 파일을 드래그 앤 드롭
5. 즉시 URL 생성!

### Vercel (GitHub 연동)
1. https://vercel.com 접속
2. GitHub 계정으로 로그인
3. `New Project` → GitHub 저장소 선택
4. `Deploy` 클릭
5. 자동으로 URL 생성!

## ✨ PWA 기능

설치 후 다음 기능을 사용할 수 있습니다:

- ✅ **오프라인 작동**: 인터넷 없어도 열림
- ✅ **전체화면**: 브라우저 UI 없이 앱처럼 실행
- ✅ **빠른 로딩**: 캐시된 데이터로 즉시 실행
- ✅ **홈 화면 아이콘**: F&F 로고 자동 생성
- ✅ **푸시 알림**: (추후 추가 가능)

## 🔄 업데이트 방법

새 데이터로 업데이트하려면:

1. GitHub 저장소 접속
2. `index.html` 클릭 → 연필 아이콘(Edit) 클릭
3. 내용 수정
4. `Commit changes` 클릭
5. 1~2분 후 자동 반영!

## 🆘 문제 해결

### "설치" 버튼이 안 보여요
- HTTPS 주소인지 확인 (http://가 아닌 https://)
- Chrome 또는 Safari 최신 버전 사용
- 이미 설치되었을 수 있음 (홈 화면 확인)

### 모바일에서 표가 잘려요
- 좌우 스크롤 가능합니다
- 가로 모드로 보면 더 편합니다

### 데이터가 안 바뀌어요
- 앱 삭제 후 재설치
- 또는 브라우저 캐시 삭제
